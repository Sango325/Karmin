# Karmin

Karmin — настольный ИИ-помощник для Windows 10 и 11 (64-разрядная версия).

**[Скачать KarminSetup.exe](https://github.com/Sango325/Karmin/releases/latest/download/KarminSetup.exe)**

Для обновления закройте приложение, включая значок в трее, и запустите новый установщик поверх предыдущей версии. Чаты, настройки и скачанные модели сохранятся.

[Последний релиз и список файлов](https://github.com/Sango325/Karmin/releases/latest)
